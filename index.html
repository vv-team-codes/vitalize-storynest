Step 4 — Character Bible (consistency lock)

The same face, hair, outfit and colours are injected word-for-word into every illustration and video prompt. Change it here and regenerate to apply it everywhere.

Step 5 — Illustrations

Every page gets a picture — first a built-in illustration, then a generated picture, one page at a time. Each picture is generated separately, so the same character may look a little different on different pages. If a picture can't be generated right now, the built-in illustration stays — a page is never left without a picture. Pictures are generated for everyone from the same service, with a fair daily limit shared across all users, so a busy day can run out — try again tomorrow.

Tip: pictures appear one by one — a 6-page book takes a little while.
